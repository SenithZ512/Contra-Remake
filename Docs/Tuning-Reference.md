# คู่มือปรับค่า — ของที่ผมตั้งไว้ให้ทั้งหมด

เอกสารนี้รวมทุกค่าที่ผมตั้งไว้ในงานรอบนี้ พร้อมบอกว่าแต่ละตัวทำอะไรและมาจากไหน

| สัญลักษณ์ | ความหมาย |
|---|---|
| **[ROM]** | ตัวเลขจากตลับจริง แก้ได้แต่จะไม่ตรงต้นฉบับแล้ว |
| **[ผม]** | ผมเลือกเอง ปรับตามใจได้เลย ไม่มีอะไรศักดิ์สิทธิ์ |

---

## ⚠️ อ่านก่อนแก้ — กับดักที่เจอแน่ถ้าไม่รู้

**กด Build Scene / Build Prefab ใหม่ = ค่าที่แก้ใน Inspector หายหมด**

เพราะเมนูพวกนี้ลบของเก่าทิ้งแล้วสร้างใหม่จากศูนย์ ไม่ได้แก้ของเดิม

```
ปรับใน Inspector  →  ใช้ได้เลย แต่หายถ้ากด Build ใหม่
อยากให้อยู่ถาวร   →  ต้องไปแก้ในไฟล์
```

**แก้ในไฟล์ไหน** ขึ้นกับว่าใครเป็นคนเขียนค่านั้น

| ถ้าค่านั้นอยู่ในตาราง | แก้ที่ |
|---|---|
| ✏️ **Builder เขียน** | `Assets/Editor/BaseStageSetup.cs` หรือ `DragonBossSetup.cs` |
| 📄 **Default ของสคริปต์** | ไฟล์สคริปต์นั้นเอง ใน `Assets/Spicpt/` |

ถ้าจูนเสร็จแล้วพอใจ **ไม่ต้องกด Build อีกก็ได้** ค่าใน Scene/Prefab อยู่ของมันเอง

# สูตรลัด — อยากได้แบบนี้ แก้ตรงไหน

| อยากได้ | แก้ |
